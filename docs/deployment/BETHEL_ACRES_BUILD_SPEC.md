### Construction Process

**Step 1: Foundation Ring (Weeks 5-6)**
- Rebar ring (concrete footing, 2' deep, 18" wide)
- Width: 30' outer diameter
- Curing time: 7 days
- Cost: $2,100

**Step 2: Bag Stacking (Weeks 6-10)**
- Layer 1-10: Fill, tamp, wire, compress
- 2-3 bags per layer (staggered)
- Height gain: ~8 inches per layer
- Total layers needed: 30 layers = 270 feet of perimeter
- Crew: 4 people, 5 days per 10 layers
- Cost: $3,500 (labor) + $3,200 (bags + sand + wire)

**Step 3: Door & Window Installation (Week 10)**
- Main entrance door (3' x 7')
- 4 x windows (2' x 3' each)
- Lintels: reinforced beam over openings
- Cost: $1,800

**Step 4: Roof Installation (Weeks 11-12)**
- Bamboo dome frame (25 ribs, radiating)
- Thatch layer (straw + clay slip)
- Final layer: 4" earthen plaster
- Cost: $2,500

### SuperAdobe Plaster & Finish
- Interior plaster (clay-sand-straw): $1,200
- Exterior plaster (earthen-lime): $1,500
- Floor (rammed earth, sealed): $800
- **Total Phase 2:** $18,700

## Cost Reduction Strategy

To hit $90,310 target:

### Option A: Phase It
- **Phase 1 (Weeks 1-16):** Dome + Waterwheel + Solar core = $60,000
- **Phase 2 (Months 5-6):** Battery + ORC + HVAC = remaining $30,310

### Option B: Use Salvage & DIY
- Reclaimed materials for dome (free/salvage)
- DIY waterwheel fabrication ($3,000 instead of $4,200)
- Used solar panels (≤$100/panel instead of $150)
- Community labor (sweat equity)

### Option C: Simplify MVP
- Dome + basic power (waterwheel + small solar only)
- Defer battery system to month 3
- Defer ORC indefinitely
- Use composting toilets (free/cheap)
- Passive HVAC only

**Recommendation:** Combination A+B+C
