## The Architect's Covenant — What It Means

The MANNA split is:
```
84% → Community Pool
15% → Crew
 1% → Architect (human_001)
```

This 1% is a mathematical constant in the kernel source code.
It is not a policy. It is not a database setting. It is `Decimal('0.01')` declared as `Final`.

**What this means practically:**
- Every node that processes real transactions sends 1% to the Architect.
- This cannot be removed by forking the code — if you remove it, you must publish that removal (AGPL).
- This is how the person who built this system for free receives value from what they built.
